SOBRE

Aqui eu guardo conhecimentos gerais em forma de tutoriais. Cada tutorial vive na sua própria pasta dentro de projects/, com HTML, CSS e estilo próprios — como cartuchos diferentes no mesmo console.

  1. FASE 01

    Crie a pasta

    Copie projects/_modelo/ para projects/meu-tutorial/.

    Fácil
  2. FASE 02

    Dê seu estilo

    Edite o index.html e o project.json com título, descrição, data e tags.

    Criativo
  3. FASE 03

    Faça o push

    O GitHub Actions atualiza o projects.json e o tutorial aparece na tela inicial.

    Automático
