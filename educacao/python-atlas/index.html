Do estudo à prática

Ambiente, módulos e instalação de pacotes

Instale Python pelo site oficial. No terminal, confira python --version (ou python3 --version). Salve seus exemplos em arquivos .py. Para importar uma função de utilidades.py, use from utilidades import minha_funcao. Não use espaços ou hífens no nome do módulo.

Crie um ambiente por projeto. Os comandos abaixo são comandos de terminal, não código para o console Python.

python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate
# Exemplo de pacote externo (precisa de internet):
python -m pip install requests
python -m pip freeze > requirements.txt
# Em outro ambiente:
python -m pip install -r requirements.txt
# Para sair do ambiente:
deactivate

Os 92 exemplos do atlas usam somente a biblioteca padrão e não precisam de pip. Organize um projeto em módulos pequenos, mantenha testes separados e use nomes descritivos em snake_case.

Erros comuns e como investigar
ErroO que conferir
NameErrorNome definido antes do uso? Há um erro de digitação?
TypeErrorOs tipos e argumentos são compatíveis com a operação?
ValueErrorO valor pode ser convertido ou está dentro do domínio permitido?
IndexError / KeyErrorO índice ou a chave existe? Use get se a chave for opcional.
IndentationErrorIndentação consistente? Misturou tabs e espaços?
ModuleNotFoundErrorPacote instalado no mesmo interpretador/ambiente em uso?

Leia o traceback de baixo para cima: a última linha informa o tipo e a mensagem; as linhas anteriores mostram o caminho até a falha. Reduza o problema a um exemplo pequeno e inspecione valores com print, repr e type ou use um depurador.

6 desafios para fixar — com caminhos de solução

1. Leia três preços e mostre o total com duas casas decimais.
2. Classifique uma nota entre 0 e 10, rejeitando entradas inválidas.
3. Conte palavras de uma frase sem diferenciar maiúsculas.
4. Salve e recupere uma lista de tarefas em JSON.
5. Crie uma classe Conta com depósito e saque validados.
6. Escreva testes para saldo insuficiente, valor negativo e saque válido.

Ver pistas e critérios de sucesso

1. Use input, Decimal a partir de string e sum; capture erros de conversão.
2. Use try/except ValueError e if/elif/else; teste limites 0, 6 e 10.
3. Combine lower, split e Counter; decida como tratar pontuação.
4. Use json.dump/load e with open; trate FileNotFoundError e JSONDecodeError.
5. Mantenha saldo por instância, rejeite valores não positivos e use Decimal.
6. Use unittest, assertEqual e assertRaises; verifique que operações inválidas preservam o saldo.
